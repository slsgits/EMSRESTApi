# EMSRESTApi
A simple **ASP.NET Core Web API** project built to understand and practice RESTful API fundamentals using a practical 
Employee Management System.

### What this project covers

* ASP.NET Core Web API
* RESTful API principles
* CRUD operations using GET, POST, PUT, PATCH and DELETE
* Routing and route constraints
* JSON Patch for partial updates
* HTTP status codes and model validation
* Entity Framework Core
* SQL Server database integration
* EF Core Migrations
* Swagger API testing
* Environment variables for secure connection string configuration

The project focuses on **practical understanding of how a REST API works from request to database and back to the client**, 
rather than building a complex production architecture.
